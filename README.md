# Simple Calculator 🧮

A simple Python-based calculator that performs basic arithmetic operations using two numbers and an operator.

## Features

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`x` / `*`)
* Division (`/`)
* User input through the terminal

## Technologies Used

* Python 3

## How to Run

1. Install Python 3.
2. Save the program as `calculator.py`.
3. Open the terminal in the project directory.
4. Run:

```bash
python calculator.py
```

## How It Works

The program takes:

1. Two numbers as input.
2. An arithmetic operator.
3. Performs the selected operation.
4. Displays the result.

## Example

```text
Enter the number: 10
Enter the number: 5
Enter the symbol: +
10 + 5 = 15
```
